Major assessments are tests, exams, quizzes, projects, essays and labs, plus other heavily weighted assignments, taken from every course in Canvas. Overlaps are counted per student, using each student's own class enrollments: two tests on the same day only count if the same student takes both. Several assessments in the same course on the same day (for example an exam's multiple-choice and free-response parts) count as one test. Teachers are shown by initials. When you filter, shading counts only students affected by the items shown. Click a ⚠ count to see which tests overlap. Data as of November 10, 2026.
